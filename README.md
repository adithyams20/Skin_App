# Skin Disease Detection App

## Project Overview

This project is a Skin Disease Detection Application developed using Deep Learning and Transfer Learning techniques. The system analyzes skin images and predicts possible skin diseases.

## Features

- Skin disease detection using CNN
- Transfer Learning with MobileNetV2
- Image preprocessing
- Disease prediction
- User-friendly interface

## Technologies Used

- Python
- TensorFlow
- Keras
- OpenCV
- Flutter
- SQLite
